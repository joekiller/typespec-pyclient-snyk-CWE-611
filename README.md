# CWE-611 from Snyk for typespec generated python clients
The client generated by the typespec generator for Python clients is vulnerable to CWE-611: Improper Restriction of XML External Entity Reference.

## Reproduction steps
The vulnerable client is generated by the typescript http-python client emitter.

```
npm install -g @typespec/compiler
tsp --version
1.2.1
tsp init
... choose REST
... include python client emitter
// update tsp config.yaml to emit to `emitter-output-dir: "{cwd}/clientpy"`
tsp compile .
snyk code test

Testing typespec-pyclient-snyk-CWE-611 ...

 ✗ [Medium] Insecure Xml Parser 
   Path: clientpy/demoservice/_utils/model_base.py, line 1201 
   Info: xml.etree.ElementTree.fromstring is considered insecure. Use an analog from the defusedxml package.

 ✗ [Medium] Insecure Xml Parser 
   Path: clientpy/demoservice/_utils/serialization.py, line 101 
   Info: xml.etree.ElementTree.fromstring is considered insecure. Use an analog from the defusedxml package.


✔ Test completed
```

### Description
Detected here: https://github.com/joekiller/typespec-pyclient-snyk-CWE-611/pull/2#pullrequestreview-2875318015

The python client generator creates clients that use an insecure XML parser for results. This generator will be used downstream and include the vuln.

```
xml.etree.ElementTree.fromstring is considered insecure. Use an analog from the defusedxml package.

clientpy/demoservice/_utils/model_base.py
```

```
xml.etree.ElementTree.fromstring is considered insecure. Use an analog from the defusedxml package.

clientpy/demoservice/_utils/serialization.py
```

There are two template locations:

https://github.com/microsoft/typespec/blob/f7fc86f9f8e04bd719757e9f4436358d322b097f/packages/http-client-python/generator/pygen/codegen/templates/model_base.py.jinja2#L1204

and

https://github.com/microsoft/typespec/blob/f7fc86f9f8e04bd719757e9f4436358d322b097f/packages/http-client-python/generator/pygen/codegen/templates/serialization.py.jinja2#L103

## Reporting
Per TypeSpec's [security policy](https://github.com/microsoft/typespec/blob/main/SECURITY.md), security issues should be reported to the Microsoft Security Response Center (MSRC) and they replied that the issue was not a Microsoft owned domain or product.

### Timeline

- Reported VULN-155035 CRM:0022093874 to MSRC May 28, 2025
- MSRC responded May 29, 2025, stating that, "We have investigated your report, and it appears that the site in question is not a Microsoft owned domain or product."
